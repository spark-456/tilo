# Tilo T: latest designs

Open **Tilo T Canvas.dc.html** in a browser. It's the hub that links to every board. Give `PROMPT.md` to Claude to apply the design.

**Included:** all Tilo T screens and boards, the motion spec, the shared tokens, keyframes and icons, and the city engine. It also includes **Tilo S Buddy**, the mascot that every Tilo T screen uses.

**Left out because a newer Tilo T version replaces them:** the Studio (S) versions of Home, Chat, World, Skills, Agenda, Team, Needs, Connectors, Nav, Components and Landing (Tilo T Landing is the Studio landing plus the new sections), Bubble (replaced by Assistant), all R files, and the older export folders.

**Not in Tilo T yet:** Settings and the Worlds list only exist as Studio pages (`Tilo S Settings`, `Tilo S Worlds`).
