# Tilo Screenshot Assets

This directory contains live application screenshots captured directly from the local running web application using sample and fixture datasets. No mock-ups are used; every capture demonstrates real functionality and views rendered by the Tilo Park frontend.

## Desktop Views (1440 × 900)

| Screenshot | Screen / View | Description |
| :--- | :--- | :--- |
| `1440-home.png` | **Home** | The central dashboard showing summary KPIs (active worlds, tasks, budget and spend), live run activity, sample worlds cards, and the prompt composer for natural language work initiation. |
| `1440-worlds.png` | **Worlds** | The Worlds directory, displaying active, in-planning, and completed world projects categorized across City, Town, and Village tiers. |
| `1440-world-running.png` | **Running World** | A live, active World (`Onboard 12 new hires`), featuring the living isometric town stage, active agents, district progress, and real-time event tracking. |
| `1440-world-result.png` | **World Result Tab** | The delivered result view for a completed World task (`Competitor pricing`), displaying the delivered analysis report, summary, and action options (Open result, Share). |
| `1440-agenda.png` | **Agenda** | The integrated Agenda view combining team and Tilo action pinboards (Needs attention, Waiting on team, Today's focus) with the weekly calendar schedule. |
| `1440-teach-tilo.png` | **Teach Tilo** | The interactive 3-step skill teaching wizard (Describe it, Show an example, Review the steps) for creating and teaching custom agent workflows. |
| `1440-team.png` | **Team** | The workspace team management page showing team members, roles, activity status, and agent permissions. |
| `1440-skills.png` | **Skills Gallery** | The catalog of built-in and taught agent capabilities with search, category filtering, and status badges. |
