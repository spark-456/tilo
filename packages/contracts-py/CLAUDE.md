# packages/contracts-py

## Purpose
Generated Python types for the `contracts/` JSON Schemas — the Python side of Tilo's single
source of truth for shapes crossing a service boundary. Package `tilo_contracts` (uv workspace
member `tilo-contracts`): pydantic v2 models such as `Brief`, `Plan`, `Card`, `Policy`, plus
type aliases for shared scalars such as `RiskTier` and `UnitId`.

## Commands
- `just contracts-gen` — regenerate `src/` from `contracts/*.schema.json`
- `just contracts-check` — fail if `src/` differs from a fresh generation (runs in `just check`)

## Contracts
- Reads: `contracts/*.schema.json` (owned by the architect; read-only from here). The event
  contract joins with ticket P0-03.
- Writes: `src/` — generated by `scripts/contracts_codegen.py` only, never hand-edited (see
  `.gitattributes` `linguist-generated=true`).

## Config
- None directly; generation is driven by `contracts/` itself (ADR-0002).

## Requirement IDs
- FR-WLD-02. Supports FR-* / NFR-* wherever a service needs a typed contract object.

## Local rules
- Nothing here is hand-written except this file and `pyproject.toml`.
- The models check shapes only. Conditional rules (`if`/`then`, `contains`) are enforced by
  validating against the JSON Schema; cross-reference rules by the validators in
  `contracts/*.rules.md`.
- CI fails on drift between `contracts/` and the generated output (schema drift = automatic FAIL).
