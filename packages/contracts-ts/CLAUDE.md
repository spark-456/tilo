# packages/contracts-ts

## Purpose
Generated TypeScript types for the `contracts/` JSON Schemas — the TS side of Tilo's single
source of truth for shapes crossing a service boundary, consumed by `apps/web`. Package
`@tilo/contracts` (pnpm workspace member), types only: `import type { Card } from "@tilo/contracts"`.

## Commands
- `just contracts-gen` — regenerate `src/` from `contracts/*.schema.json`
- `just contracts-check` — fail if `src/` differs from a fresh generation (runs in `just check`)
- `pnpm -r exec tsc --noEmit` — type-check (part of `just typecheck`)

## Contracts
- Reads: `contracts/*.schema.json` (owned by the architect; read-only from here). The event
  contract joins with ticket P0-03.
- Writes: `src/` — generated by `scripts/contracts_codegen.py` through `scripts/json2ts.mjs`
  (json-schema-to-typescript), never hand-edited (see `.gitattributes` `linguist-generated=true`).

## Config
- None directly; generation is driven by `contracts/` itself (ADR-0002).

## Requirement IDs
- FR-WLD-02. Supports FR-* / NFR-* wherever `apps/web` needs a typed contract object.

## Local rules
- Nothing here is hand-written except this file, `package.json`, `tsconfig.json` and
  `scripts/json2ts.mjs`.
- The types check shapes only; conditional and cross-reference rules live in the schemas and
  `contracts/*.rules.md`.
- CI fails on drift between `contracts/` and the generated output (schema drift = automatic FAIL).
